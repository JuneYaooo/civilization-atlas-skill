# 采集范围与推进顺序

目标是从约公元前 3500 年以来逐步建立跨地区历史知识库，并保留更早的相关材料。不存在可核验的“全部历史信息”分母，因此按地区、时期、主题和来源类型检查覆盖，不声称穷尽。

## 信息组织

| 层次 | 当前实现 | 需要补齐 |
|---|---|---|
| 来源与版本 | 下载地址、内容摘要、获取时间、定位 | 初次公开时间、修订链、撤回订正 |
| 主体与关系 | 来源内政体、国家、联盟和参与关系 | 有效期跨来源身份映射、疆域版本、非国家网络 |
| 历史事件 | 既有条目、战争与危机资料 | 各区域系统年表、史料差异、事件内部阶段 |
| 长期状态 | 社会结构与现代五项指标 | 前现代人口经济、财政、技术扩散、价格、能源 |
| 自然冲击 | 现代全球温度、部分危机编码 | 地区古气候、灾害暴露、疾病传播、粮食冲击 |
| 原文证据 | 数据集、代码和既有机构引用入口 | 合法可得原文、章节／页码、原文断言与争议 |
| 机制解释 | 由研究过程单独生成 | 正反证、边界条件、失败路径、可迁移性评估 |

文献目录、取得文件、可检索全文、已审读内容和核实的断言须分别计数。向量索引只能帮助召回，不能替代证据定位、结构化身份和年代约束。

## 主题队列

下列来源为后续候选，未标记为已接入，实际获取后才写入 acquisition manifest。

| 主题 | 补充信息 | 优先来源入口 | 主要核验问题 |
|---|---|---|---|
| 长时段经济 | 产出、收入、实际工资、物价、贸易 | Maddison Project、Clio Infra、历史国民账户 | 重建方法、单位、疆域、插值与缺测 |
| 人口与家庭 | 人口、死亡率、生育、迁移、城市规模 | 历史人口研究、HYDE、联合国人口资料 | 模型估计与人口普查分开，样本稀疏期不补成逐年观测 |
| 财政与国家能力 | 税种、税负、支出、债务、行政覆盖 | 各国史料汇编、学术数据附录、财政史研究 | 名义值、实值、税基与制度口径变化 |
| 战争与国际关系 | 战争更新、外交、殖民、贸易和条约网络 | UCDP、COW 后续版本、条约与外交档案 | 分母、暴力门槛、独立与附属身份 |
| 科学与技术 | 突破、应用、成本下降、扩散率、互补设施 | 博物馆／科学院／专利局资料、学术技术史 | 首次发现、规模化与普及区分；论文数不是技术效能 |
| 气候与资源 | 地区温度／降水、火山、干旱、粮价、能源 | NOAA 古气候、PAGES、火山与气候重建论文 | 代理指标、年代误差、局地与全球尺度 |
| 疾病与灾害 | 疫情范围、死亡、救济、暴露与脆弱性 | WHO、历史流行病学、灾害数据库、档案 | 报告激励、漏报、事件定义、许可 |
| 文化与制度 | 教育、文字传播、宗教、法律、阶层和组织 | 机构馆藏、原典数据库、社会史与法律史研究 | 作者立场、翻译版本、社会内部差异 |

## 一次采集的完成标准

明确采集对象与覆盖域；保存原始版本及来源条款；核对编码说明；检查重复、缺测、时间区间和统计单位；提供检索与定位；记录不能确认的断言；更新覆盖矩阵。不得用翻译、插值或跨年复制增加“史实条数”。

事件密集不等于历史重要性高。史料保存较少的地区需要单独登记搜索过的来源及未找到结果，避免将“未找到”解释为“没有发生”。不同著作重复同一上游史料也不能算独立证据。

下一批应优先补齐前现代经济人口与各地区制度／科技年表的原文证据，再将自然冲击和事件过程关联起来。不能只继续堆积现代年度指标来掩盖早期历史缺口。
