# Civilization Atlas Skill

以比较历史、复杂系统、制度分析及周易的时位与关系思维，研究社会变化、未来趋势和不确定性下的决策。

此仓库为纯方法发行版，包含研究内核、方法参考、文献索引和记录工具。无内置案例、演示数据、历史预测报告、测试问答或个人资料；不继承其他研究仓库的Git历史。

## 安装

克隆或下载本仓库，在目录内运行 `python3 scripts/install_skill.py`。默认安装到Codex技能目录；已有同名目录时停止，不覆盖。`--dest`指定技能父目录，`--zip`生成安装包。

在支持Skill的会话中调用 `$civilization-atlas`。研究入口见[SKILL.md](SKILL.md)。Python工具只依赖标准库。

## 能力与边界

- 核对史料、信息时间与来源依赖，区分观察和解释。
- 比较竞争机制，检查历史迁移条件、反馈、约束与结构变化。
- 制定预测检验、干预识别和自适应决策方案。
- 校验研究记录、冻结内容并追加复盘。

这些能力支持研究流程，不等于已经证明通用预测准确性或决策收益。周易提供解释与问题启发，不生成未经校准的概率、日期或因果系数。

运行产生的资料保存到仓库外。发布内容按显式清单检查，不自动收集本地研究文件。
