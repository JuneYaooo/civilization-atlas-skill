# 历史知识库检索

用于已有历史数据和文献集合的研究。方法流程与知识库内容各自更新；已安装 Skill 不代表已取得某个历史资料库。

## 定位与调用

优先使用用户指定的知识库路径或环境变量 `HISTORY_KB_PATH`；也可检查当前项目或相邻目录中的 `history-knowledge-base`。确认目录包含 `data/history.sqlite` 和 `scripts/query.py` 后再调用，不把相同名称视为内容一致。找不到时明确资料尚未接入，不声称已查阅知识库。

本项目知识库接口使用 Python 标准库：

| 子命令 | 用途与参数 |
|---|---|
| `coverage` | 读取已入库范围和来源集合 |
| `entities` | 通过 `--q` 查询来源专属主体标识 |
| `search` | 使用 `--q`、`--source`、`--topic`、`--entity`、`--start`、`--end`、`--limit`、`--offset` 筛选记录 |
| `record` | 输入记录 ID，读取原始断言、来源摘要、定位和关联记录 |

以上命令均通过知识库的 `scripts/query.py` 调用，`--help` 给出实际接口。查询程序只读；回答问题无需重新下载或重建全部数据。

## 研究使用

先检查覆盖，辨认数据是事件、属性、状态段、年度指标、变量说明还是缺测记录。确定主体身份，再检索相关时期和变量，读取条目详情及来源定义。按需要补充原始史料，不能把导入来源编码称为已独立核实的事实。

报告重要依据时保留来源标题、版本或获取日、文件摘要及行号／字段定位，提供原始来源链接。数据库命中数不能替代独立证据数量。旧编纂的审核状态只能继承，不能因迁移而升级。

## 易错边界

- 国家、经济体、聚合地区、古代政体和联盟分别识别；同名不自动合并。
- 未注明年代的属性可按政体检索，但不能用政体起止年填成逐年观察。设置日期筛选可能排除这些条目，应另查未注明年代的关联资料。
- 持续状态、年代不确定区间和多次事件的外包络不是同一种时间语义；读取原始字段后再解释。
- 空值、来源特殊代码、争议与推断状态保留；不将未知编码为零或未经校准的概率。
- 来源结束时仍存在的联盟不代表一直延续至今；地区聚合值也不能按今天成员名单回填历史。
- 取得最新快照不能证明过去预测起点时已可得。原始版本缺失时，只能标为历史重建。

当问题超出知识库覆盖时，说明具体缺口并从机构资料、开放学术数据和合法可得史料继续采集；新增资料保留版本、原文定位、编码定义与范围，再更新覆盖报告。不能靠生成事件、插值或复制跨年记录补足资料数量。
