# 动态检索策略

用于“最近、今天、刚发生”或依赖现行政策、技术与市场条件的问题。先取当前事实，历史检索随后开展；不要先用旧库给出当前结论。无联网工具时说明无法核实截至指定时点的情况，仍可给出明确条件下的历史分析。

## 四层检索

| 层 | 目标 | 停止与转换条件 |
|---|---|---|
| 事实核查 | 当事方原文、当地主管机构、统计定义、事件时间和信息发布时间 | 核心事实有可读出处；若冲突影响决策，保留分支而非选多数 |
| 机制与解释 | 论文、技术资料、专业研究及证据链 | 明确支持哪条因果边、研究适用范围和最强替代解释 |
| 历史比较 | 相似结构、不同结果、未发生危机的对照 | 能说明可迁移条件与破坏类比的差异；不必强行找到类比 |
| 更新核对 | 更正公告、版本修订、新事件与行动触发信号 | 回答提交前核对会改变结论的更新；持续监测须另有用户授权 |

使用宿主实际可用的搜索/浏览工具。`scripts/search_plan.py` 产生四层查询草案和来源入口；它不执行搜索，查询可按语言、辖区和官方名称改写。若原问题有私人信息，只用抽象决策结构和公开事件关键词检索。

[来源索引](source-routes.json) 是入口，不是已经查阅的证据或权威评分。官方来源更适合确认其发布的数据/规则，但对自身行为的解释仍可能有立场。WHO 疫情通报并不覆盖所有事件，未检索到不等于未发生，见其[范围说明](https://www.who.int/emergencies/disease-outbreak-news/)。IMF WEO 的版本入口适合核对版本，访问失败时不得说已读取。Financial Times 的报道、Nature 的新闻和研究论文应区分文类，不因品牌合并证据等级。

生成查询草案：

```sh
python3 scripts/search_plan.py --mode event --question "公开事件关键词" --topic health --as-of 2026-10-09T12:00:00+08:00
```

个人决策使用 `--mode personal`；`--topic` 可重复，具体选项见 `--help`。截止时间按实际任务填写，不沿用示例日期。未列入来源索引的领域仍需定向检索本地主管机构、原始研究与独立报道。

## 证据卡与冲突

每个影响结论的主张保留：主张 ID、来源 URL/标题、发布或版本时间（未知就写未知）、访问时间、事件/观测时间、定位、实际阅读范围（全文/节选/摘要）、原始上游和支持/挑战关系。摘要只提供线索，不能称为阅读全文；未访问的页面不能写成“已核实”。

冲突先查定义、地域、样本、时间窗和修订版本，再判断事实分歧或解释分歧。转载同一通稿只算一个上游；不同来源同样引用某研究，不形成多次独立验证。无法解决时保留各分支及其行动影响，不取平均来消除冲突。

发布时间、首次可得时间和观测时间分开记录。研究过去时不能把后来修订内容配上旧发布日期。普通网页缺少版本证据时，标记历史重建或可得时间未知。

## 研究预算

初答优先核实决策敏感的事实；扩大检索到新证据不再改变行动排序或达到预算时停止。记录查过的路径和关键未解决问题，不用来源条数作为充分性的替代。数值区间注明来自样本估计、模型、专家意见还是情景假设；没有计算依据不写“30—50% 不确定性”。
