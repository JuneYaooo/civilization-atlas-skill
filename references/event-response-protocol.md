# 当前事件到行动：六步研究协议

用于分析近期公共事件对地区、行业或个人的影响。顺序可按问题简化，但当前事实与历史证据不可混为一谈。

1. **界定任务**：明确事件、截止时点和时区、受影响主体、目标量与期限。若用户需要建议，识别其暴露渠道、可选行动与不可逆代价；缺少个人信息时先给公共影响与条件选项。
2. **建立事实快照**：按[检索策略](online-search-strategy.md)核对当前原始公告、事件/发布/修订时间及争议。按[多渠道取证](source-diversity.md)补查一线执行与受影响者的独立记录，区分规则、实际经历和总体分布。先记录已知与未知，再解释。旧库用来补历史，不决定今天发生了什么。
3. **展开传导链**：事件→直接暴露→主体响应→价格/数量/制度变化→分配结果。逐条标记证据、竞争机制、时滞、缓冲能力、反馈和可能反转条件。总量变化不自动等于每个地区或群体的变化。
4. **提出历史参照**：先定结构特征再寻找候选，包括相似冲击不同结局、相似结局不同机制及无危机对照。可用 `scripts/event_matcher.py` 排序有出处的候选；结果仅用于安排阅读，不能输出发生概率。按[机制迁移协议](mechanism-transfer.md)逐项比较源环境与目标条件；说明传播/作用与发现/响应的竞争、阶段切换和观测变化。给出迁移、条件迁移或拒绝的理由；找不到就不用。
5. **形成条件判断与行动**：区分短期直接冲击、中期调整、长期制度/技术变动。对主要情景说明成立条件、反证信号和受益/受损主体。行动表包含选项、前提、成本、可逆性、失败条件、最小试验及退出信号。无已校准概率时不用情景数量或匹配分数代替概率。
6. **交付与复盘**：先回答问题，再给事实出处、历史增量、替代解释、关键未知与修订触发点。可结算判断按[记录协议](recording.md)保存到研究目录，保留原结论。监测建议只是可观察信号，不自动创建任何后台任务。

## 主导因素是待检验假说

疾病、气候、灾害、技术可成为冲击，也可能与制度和行为相互影响。战争、经济与国家关系既可能是结果，也会反馈改变约束，不预先分为纯外生/纯内生。

对“本期主导因素”说明：它改变哪一项约束，为何在该期限比其他因素重要，若它缺席是否仍预期同一结果，以及什么证据能区分这一解释。不要编造固定权重。技术性能增速、采用率、互补投资、组织改造和社会收益分别测量；指数趋势需检查饱和、成本、资源与制度瓶颈。

## 输出验收

读者能区分已核实事实、作者解释、待检验机制、条件预测与价值选择。每项建议能回到具体暴露与约束。历史没有提供增量时直接说明；不靠名人故事填充答案。
