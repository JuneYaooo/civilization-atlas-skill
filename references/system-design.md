# 从 Skill 到研究系统

用于规划持续研究、数据采集与预测服务。此文是架构与验收建议，不表示这些服务已经实现或有效。

## 按可预测任务组织能力

一个模型的能力用目标、单位、期限、信息条件和评估范围描述。状态延续、转移风险、转移时点、变化幅度及聚合趋势分别验证。总体分布可预测，不代表个体轨迹可预测；风险排序好，不代表概率已校准。

在同信息条件下检验历史带来的增量。历史可提供机制、边界、参数范围与时滞；未必适合直接训练。区分长时段机制材料、可比历史面板与实时版本账本。年表作为查询视图，不作为唯一数据结构。

## 模块及接口

| 模块 | 输入与输出 | 验收重点 |
|---|---|---|
| 任务注册 | 研究需求 → 目标口径、风险集、期限、损失与结算协议 | 无需阅读解释文章也能判断如何结算 |
| 来源与测量 | 材料 → 有定位和版本的断言、观察与不确定性 | 不将未知填零；数据契约可追溯 |
| 身份与关系 | 单位/成员/边界沿革 → 时点映射和关系网络 | 不用现代身份或最终成员回填过去 |
| 机制与预测 | 同截点信息 → 基线、候选模型及条件路径 | 区分经验支持、项目假设和未知参数 |
| 独立评估 | 冻结协议与预测 → 匹配样本误差、覆盖和失败诊断 | 模型选择不接触最终留出；分组依赖有处理 |
| 决策更新 | 可信路径与可行行动 → 损益、触发与修订规则 | 可观察信号留出实施时间；收益须单独验证 |

先保证版本化文件、关系表和时点查询可复现，再按实际查询需要引入图数据库或仿真。LLM 可辅助提取候选与提出机制，事实认证、数值计算和结算依赖可核验资料与程序。

需要地区或领域并行研究时，各研究共享任务和[数据契约](data-contract.md)，保留来源依赖和不一致。多个研究者意见相同不形成独立样本或概率。是否使用 agent 取决于任务授权和独立工作机会。

## 学习闭环与升级门槛

先冻结任务和简单基线，重建符合信息截止的数据，再增加可区分的机制。比较同一信息和研究资源下的表现；分别做跨时间、跨区域和真正事前检验。LLM 可能记得历史结果，遮住提示中的结局不能自动消除训练污染。

持续记录未改进、弃权和未知结果。对大误差追踪过程时保留正常结果的比较对象；事后找到解释只能提出下一轮假设，不回写成上一轮预测能力。

升级证据分开登记：工程可复现、测量可靠、机制支持、回溯增益、实时增益和行动收益。任何一项通过均不自动授予其他能力；新解释、新变量和更复杂的模型需接受同样比较。

对尚无可靠参数或缺少转折前信号的任务，提供条件路径、界限与监测需求。精确时点不由叙事、固定周期或情景数量推得。

## 信息投入

优先补齐结果定义、风险分母、单位边界和数据版本，再按任务补存量/流量、分布/网络、规则/执行、行为/信息、过程顺序和反馈时滞。约束、利益、身份、信任与选择集合须进入可观察的研究问题，不设恒定人性系数。

区分“没有足够样本”“没有测到关键状态”“测量噪声”“未来新冲击”“学习不足”和“机制改变”。这些诊断可以并存，不能仅从预测误差唯一识别。新增变量、更多样本、更及时观察与缩短期限解决的问题不同。

周易转译仍遵循[独立的文本和经验边界](yijing.md)。其贡献可以是问题形成与价值澄清；主张预测增益时，需冻结转译方法并独立检验，不随结果改换解释。
