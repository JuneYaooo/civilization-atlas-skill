# 现代危机资料的采集顺序

按决策相关性、缺口、来源可追溯性和维护成本排序，不按事件热度或固定案例数凑齐。

| 优先补齐的层 | 最小内容 | 用途 |
|---|---|---|
| 事件身份与版本 | 事件起止、地域、定义、公告与修订时间 | 防止同名混淆与事后信息混入 |
| 当时状态与分母 | 暴露人口/机构、正常时期和未发生事件对象 | 防止只收集危机造成选择偏差 |
| 过程与响应 | 冲击、约束、政策、行为、资源缓冲、反馈及来源定位 | 形成可挑战的机制链 |
| 后果与异质性 | 多期限结果、地区与群体差异、结果定义与数据版本 | 不把总量结果转借给个体 |
| 迁移与反证 | 成立条件、结构差异、相反结果、剩余缺口 | 支持当前研究与弃权 |

先补公共卫生事件、近期金融/债务压力、能源与贸易中断，再依查询需求补灾害和科技扩散。每类先完成一个有来源与对照的研究单元，再扩大；“8 个危机”“16 个人物”不是质量门槛。

[来源入口](source-routes.json)与知识库覆盖报告分开维护。来源入口不是新增历史事实；候选摘要不是完整因果链。先保存书目和具体出处，阅读后才编码候选。完整研究记录按 casebook 协议保存，数值预测另行冻结。

数据状态使用待检索、已定位、已阅读、已编码、已复核等明确标签。记录逐条最后核查时间和未解决争议；禁止把整个包的构建日批量当成所有条目的更新日。许可不允许随包分发时保留官方入口，不复制受限制数据。
