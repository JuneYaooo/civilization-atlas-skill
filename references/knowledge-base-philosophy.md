# 索引、动态研究与历史推断

三层互补，而非用搜索取代数据：

1. 本地层：保留有出处、可复现的历史断言和长期序列；轻量来源索引帮助定位外部资料。记录数、体积与因果证据强度分开衡量。
2. 动态层：宿主 agent 使用可用搜索、浏览或获授权的数据接口核实当前事件，再检索可比历史。查询计划脚本不自带搜索服务，不会自动下载或监控。
3. 推断层：将事实、机制假说、条件预测、价值目标与行动分开；历史只能贡献得到证据支持的部分。推断采用[机制迁移记录](mechanism-transfer.md)，将历史与当前条件、作用与响应的竞争、阶段变化及观测变化连到具体证据；目录排序不代替迁移判断。

现有知识库是固定快照。构建日不是各条资料的观测日，表的结束年份不是所有主题的覆盖截止。动态网页也不是无限覆盖：索引偏差、删改、付费墙、语言与报道延迟均可能留下缺口。缓存修订值不能重建当年的信息集。

## 存储与升级

安装包保持紧凑，当前体积由打包程序的实际输出核对。大规模新增数据先检查许可、使用频率、版本需求与离线价值，再决定随包、外部缓存或仅存来源入口。保留已有可追溯资料，不以固定体积指标为由丢失出处。

用户研究产物放在安装目录外：保存问题、截止时点、来源版本、证据定位、冲突、选择依据、行动与复盘。只缓存合法可保留的内容；无权保存全文时存书目信息、定位与简短摘要。

## 有效性如何检验

工程指标：最新事件是否先查当前事实、能否追溯每项重要主张、无结果时是否弃权、安装后工具是否可执行。
研究指标：历史参照是否改变了问题、边界或行动；是否搜索失败和反向案例；能否区分替代解释。
预测指标：同信息截止、同研究预算，比较“只看当前证据”和“加入历史研究”的同题结果，报告覆盖、弃权、误差与校准。分开记录真实事前任务与历史重建。
决策指标：建议的可行性、不可逆损失与后续收益，不能由预测得分替代。

5—10 分钟可以作为初步答复预算，不能承诺在该时间内得到准确答案。预算内先交付可核验事实和条件判断，证据不足则明确下一步取证及其决策价值。
