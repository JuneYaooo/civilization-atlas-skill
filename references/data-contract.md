# 历史与社会数据契约

用于设计采集、接入数据或准备模型评估。以下是概念契约；按任务选择字段，不要求所有研究都建完整仓库。

## 从任务定义分母

先定义目标结果、分析单位、可发生结果的条件和观察区间。事件资料之外需要风险集：哪些单位在哪些时期处于可发生目标事件的状态。首次发生、再发生、持续、加重和结束有不同风险集；正在发生的状态不一定仍处于首次发生风险中。

明确观察进入与退出、已持续时间、重复事件规则及删失。观察结束时尚未发生不表示永不发生；观察开始前已持续的过程也不是从零开始。按结果选出的“大事件”不能直接估计发生率。

## 信息对象与关键字段

| 对象 | 必要语义 | 容易遗漏的区别 |
|---|---|---|
| 研究任务 | 目标定义与版本、单位、时间尺度、预测起点、期限、结算与用途 | 描述、检测、提前预测、条件路径与干预效果 |
| 单位及成员关系 | 稳定标识、类型、有效起止、前后继关系、边界版本 | 地理区、行政区、政权、组织和联盟；名称不是身份 |
| 来源版本 | 出版/发布日、获取日、版本、定位、许可、文件摘要和上游来源 | 今天获取旧版不等于旧版当时不可得；获取日也不是首发日 |
| 测量定义 | 概念、操作化、量纲、分母、空间覆盖、时间粒度、采集与编码过程 | 原始观察、专家评价、模型重建、插值和预测 |
| 观察记录 | 单位、变量、值或区间、适用时间、首次可得时间、来源版本、状态 | 未发生、缺测、不适用、有争议、推断存在/缺失、未结算 |
| 事件/状态段 | 结果、起止区间、进入/退出条件、强度、重复规则、影响对象 | 起始、检测、公开、结束；持续过程不逐年重复为新事件 |
| 关系/网络 | 节点、边类型、方向、权重语义、有效期、可得期、覆盖 | 正式关联、实际作用和共同外因 |
| 机制命题 | 源证据、条件、过程、尺度、时滞、替代解释、反证、迁移限制 | 作者解释、经验识别和本项目推论 |
| 预测及结果 | 任务版本、截点、模型/代码版本、输入摘要、完整覆盖、输出、结果版本 | 原预测与修订；未预测与预测未发生；初步与最终结果 |

同一事实可以有多个来源断言，不强制提前合并成唯一真值。争议是不同断言，不等于把数值取平均。区间端点须保留含义：年代范围、测量误差、专家分歧和预测区间不能混用。

## 双时间与派生链

保存事实适用的时间与信息可获得的时间。使用 BCE 年代时声明纪年法、年零约定和转换规则；不能用文件日期代替事件年代。资料只有区间分辨率时，不填出未经支持的精确年份。

为每个预测截点构建可用信息视图。派生量的全部父输入、拟合参数、单位映射和编码判断均须符合可得性限制。禁止用整段历史插值、最终成员资格、事后划分阶段或全样本标准化回填早期特征。

区分三种评估资料：当时版本重放；仅时间切分但使用后来修订值的历史重建；未来发布后等待结算的实时检验。不能把它们合并为同一种验证。旧版本缺失时直接标记，不推造发布日期。

## 测量与单位迁移

检查统计口径、记录激励、覆盖范围及测量方法是否变化。缺失整条事件、已知事件的属性缺失和属性测量错误需要不同处理。源文献撤回或订正时更新支持状态，保留原版本供审计。

跨数据库合并依据有效期标识和变量含义。按年份连接只是技术操作，不证明概念或疆域可比。总量、比率、加权均值、年末状态和年度任一发生不能沿用同一种聚合规则。

不同版本的潜变量量表可能整体重估。未经量尺对齐，不能直接把跨版本差异解释为现实变化。发布频率不等于真实观测频率；把同一估计复制到多期不会增加独立信息。

## 接入验收与采集优先级

检查标识/关联、单位有效期、时间先后、量纲、重复、缺测状态、来源定位、版本与许可。连接前后检查键的唯一性、预期对应数量和样本增减；单位沿革表的多行不能无意变成重复权重。规范化标识保留原值与转换规则，连接失败不得静默当零。风险集和观察覆盖应可重建，排除或弃权必须保留原因。结构检查通过不代表史实、测量或因果正确。

新增采集先说明它能减少哪类未知：样本不足、关键状态未观测、测量粗糙、未来冲击、模型学习或跨时期失效。记录它可能改变的机制判断或行动、获取成本和等待时间。更多变量不必然更好；在固定任务与有限样本下，应检验其样本外增量。

原始资料、研究对象、运行记录和结算结果存储在用户指定的外部研究目录，不进入公开 Skill。
