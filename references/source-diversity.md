# 多渠道取证与社会经验

涉及社会变化、趋势或重要决策时，在因素展开之后建立来源覆盖图。目标是发现不同位置的人能看到什么、哪些信息可能被过滤，以及缺失证据是否会改变结论。机构信誉、来源数量与观点多样性不能代替主张核验。

## 从需要回答的问题选择渠道

| 证据任务 | 可用渠道 | 能支持什么、还需核对什么 |
|---|---|---|
| 制度、总量与公共行动 | 公告、统计、档案、法律文本、预算 | 核实规则与口径；政策意图不等于执行，发布方对自身行为的解释需独立核对 |
| 机制与适用条件 | 论文、技术报告、系统综述、研究数据 | 核对识别、样本和外推边界；学术结论也可能共享数据或存在发表偏差 |
| 事件经过与问责 | 原创新闻、调查报道、地方报道、庭审和调查记录 | 核对采访对象、时间线、原始材料与编辑取舍；报道品牌不自动认证具体事实 |
| 具体处境与行为 | 回忆录、日记、书信、口述史、纪实作品、民族志、访谈 | 发现恐惧、激励、信任、隐性成本与执行差距；区分亲历、转述、重构与事后解释 |
| 组织运作与交易 | 行业资料、财报、招聘、招标、工作记录、从业者讨论 | 查实际部署、需求与瓶颈；注意商业动机、披露范围和参与者选择 |
| 早期信号与被忽略经历 | 社区记录、论坛、社交媒体、求助信息、音视频 | 发现待调查的局部现象；核对原始账号、日期、地点、编辑和重复传播，不能把热度当发生率 |

依相关性取证，不要求每题凑齐所有渠道。涉及行为或实际执行的重要判断，不能只凭制度文本、汇总统计或当事方自述结束研究；定向寻找受影响者、一线执行者及可相互核验的独立记录。来源难以取得时，明确未覆盖的角色和对结论的影响。

权威性按主张判断。个人日记可以直接证明作者当时记录了何种体验，不能单独估计整个社会的比例；官方公告可以证明公布了何种规则，不能单独证明所有地方实际执行。经过定位核验的亲历材料不一律降为“仅供线索”，未经核验的匿名转述也不因生动而升级。

## 来源覆盖图

在 Skill 目录外的研究笔记中，按关键问题记录：

- `question_or_mechanism`：待核实的事实或机制环节。
- `actor_positions`：决策者、执行者、承受成本者、受益者及缺席者；按问题选择。
- `channel_and_language`：实际渠道、地区及语言；必要时查当地语言与跨地区资料。
- `evidence_ids_and_upstreams`：已读证据及共同上游；同一访谈的多次转载只算一条证言。
- `status_and_access`：已读、仅定位、无法取得、未搜或不适用，以及正文/节选/摘要范围。
- `gap_and_decision_effect`：缺什么、为何可能改变情景或行动；不适用也说明简短理由。

将覆盖图与实际证据对应，不预填“广泛验证”。覆盖图是宿主研究记录，不是现有 Python 校验器自动完成的覆盖认证。

## 从叙事发现机制，再追踪验证

熟悉感可以提出问题：相似的是表面情节、人的反应、信息传递、激励结构还是制度约束？把叙事拆成行动者、当时可知信息、选择及代价、实际行动、他人反应和结果。逐项标记原文观察与作者解释，形成可证伪的过程假说。

沿假说寻找不同位置的证言、同期原始记录和不同结局的对照。问：谁面临同样处境却采取不同动作？哪些制度、技术、信息或关系条件改变了行为？再按机制迁移协议评估。不要从相似的恐惧、语言或故事结构直接推出相同宏观结局。

书籍需记录版本、章页或电子定位、叙述事件时间和成书时间；有来源注释时继续追溯。目录、书评或出版社简介只能证明其介绍内容，不能冒充正文审读。历史截点研究中，后来出版的回忆即使叙述早期事件，也只能放在事后复核，除非另取得当时可得原件。

涉及人性和社会演进时，周易的时、位、关系可帮助提出角色、激励、合作冲突和转变问题；具体动机仍须由过程证据支持，不能从经典术语推定人物内心。

## 独立性、冲突与停止条件

追溯引用链、共同数据、采访对象及资助利益。多个域名不等于独立来源；立场相反也不等于事实证据独立。不做机械的双方各占一半，不把经反驳的说法与可靠证据等权处理。

对冲突区分事实、口径、观察位置、时间与价值分歧。幸存者和愿意受访者并不代表沉默者；删失、审查、恐惧、商业保密、平台推荐和档案留存都可能改变可见样本，须检查具体证据，不能预设其方向。没有材料不等于没有经历。

关键事实有相互核验的出处，重要角色与竞争机制经过定向检索，且新增独立材料不再改变判断时，可以停止；时间或访问预算先耗尽则说明仍存缺口。禁止以搜遍互联网为承诺，也不能用堆积弱来源换取确定口吻。

交付时概括实际查阅的渠道、最关键的冲突或缺口，以及新渠道是否改变了判断。不必展示完整内部覆盖图，但不能将单一渠道研究称为全面验证。
