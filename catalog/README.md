## 阅读与使用

`review_status` 表示已阅读来源相关片段并完成编码，不代表经过独立史学审稿。`access_method` 区分实际打开网页与搜索服务返回的可阅读页文片段；普通结果摘要不能升级为正文。没有逐一确认网页版本发布时间的条目保留 `available_at: null`，因此匹配保持 provisional，不能用于冒充事前资料的回测。

这些是目的性选取的资料入口，人物偏向文献丰富、后世知名者，危机偏向已经发生的重大事件。它们缺少总体分母与系统性反例，不能估算成功率、灾害发生率或历史周期。应根据当前研究补充非事件对象、失败经验和竞争机制；允许无合适参照。

先核对观察，再审查机制，最后才讨论迁移。人物行为的候选解释不是已知的内心动机；危机的传导叙述不是逐条识别的因果效应。不要把作者自述、纪念机构传记或参与机构总结视为无偏记录。

条目只保存书目链接、定位和简短原创分析，不收录第三方网页全文。第三方原文适用各自许可；本目录原创标注采用 CC BY 4.0，署名 Civilization Atlas contributors。
