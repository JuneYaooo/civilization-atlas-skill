## 实际复核

房地产数据说明数量和价格不能混用：1998—2003名义开发投资约增长180.94%，商品住宅销售均价约增长18.50%；1999均价仅增长约0.16%。2021新开工下降11.4%，开发投资仍增长4.4%。具体来源、口径和局限见报告。

新冠报告把WHO当时资料与后来的症状前传播研究分开，并复核国际旅游的长期冲击。没有将后来观测倒填成当时已知的传播参数。

AI报告保留2023写作实验与2025编码实验各自的适用范围，并新增METR 2026更新：技术与使用状态可能变化，同时样本选择和时间测量限制了新效应量的可信程度。不能用两项不同实验的差值估计某个条件的因果作用。

## 复现记录校验

在仓库根目录运行：

```sh
python3 demos/three-question-rerun/replay.py
```

[audit.json](audit.json)记录原始文献日期、查阅范围、四个截点及八条机制比较；[results.json](results.json)保存运行结果与内容摘要。

脚本实际检查：

- 历史输入的文献日期及已知修订日期不得晚于截点。
- 共享机制校验器核对八条比较的条件、证据引用和迁移边界。
- 复算前轮十条事后假说的结果数字，保留其原始身份，不冒充本轮事前预测。
- 五个负向测试：后见资料泄漏、未知条件的无条件迁移、缺失引用和准确率标签误用必须被拒绝。

本轮采用研究专用历史对照，未将它们伪装成内置八项危机目录的匹配结果，也未重跑完整 `research_engine.py` 命令链。报告中的条件扰动是作者手工审读，不是独立模型行为实验。当前网页的原始文献日期可核对，但未取得全部精确历史网页版本；通过日期校验不等于恢复了当时完整信息集。

这些记录支持核查分析过程，不能验证史料全部正确、因果机制成立或方法优于基线。预测效力仍需未知结果的预先登记、独立结算及同题基线比较。
