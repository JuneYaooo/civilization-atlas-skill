# 研究引擎端到端验证

2026-10-09 使用 Codex 宿主的真实联网工具定位并阅读来源，再通过研究引擎执行本地查询、证据登记、默认历史匹配、报告校验和冻结。不是单独运行 Python 就自动完成网上研究；报告的语义判断由宿主 agent 完成。

| 路径 | 核查重点 | 完整记录 |
|---|---|---|
| 近期事件 | 读取 WHO 2026-10-08 公告，比较跨境响应机制及不同结果，不从输入病例直接外推全球冲击 | [报告](event.md) · [来源、检索与冻结记录](event.json) |
| 个人决策 | 从生计和能力组合出发，处理卡森资料的年份差异及退出原因不确定性 | [报告](personal.md) · [来源、检索与冻结记录](personal.json) |

每条路径包含四层实际检索或原页复核记录、三条证据及一次本地查询。时间戳为同一研究会话中整理检索记录的时间，非搜索服务提供的逐次精确执行时间。未知网页版本日期仍为 null。所选目录条目保持 provisional，不表示已证明可迁移。

事件路径没有独立核验所有国家原始报告，个人路径没有当前个人约束或职位数据，因此只输出限定条件下的研究判断。来源中的部分日期和因果解释仍有争议，记录保留这些缺口。

```sh
python3 demos/research-engine/replay.py
python3 -m unittest discover -s tests -v
```

回放读取已冻结记录、核对内容摘要并重跑校验流程，同时检查未来来源被拒绝。它不会重新联网，也不测量预测准确率。单元测试另外覆盖搜索不可用、摘要证据、不明历史版本、过期当前证据、条件冲突、缺失引用、无参照弃权和报告篡改。

[运行记录](run-receipt.json)保留两条报告的摘要。已有 WorkBuddy 截图展示的是之前的知识库查询与数值回放，本页是新研究引擎在 Codex 的独立验证。
