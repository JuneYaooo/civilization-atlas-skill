# 新机制是否有效：验证与未通过项

2026-10-09验证结论：**对显式结构错误的防护有增量；候选机制有外部研究依据；尚未证明整个 Skill 的推理或预测准确率提高。** 三类语义错误仍能通过程序，因此不能用“校验通过”认证研究结论。

这次分为固定版本的程序对照与真实文献的机制核对。没有执行独立模型的盲测，也没有真实事前预测结果；不将作者自写的更好答案当成新版模型成绩。

这些题是针对已知规则构造的合成压力测试，绝不是15次真实预测，也不能估计真实使用的漏错率。八项新增防护说明工程行为改变，不证明宿主会主动发现或正确编码冲突。

三个未通过项尤其重要：

1. 文本把历史容量写为无限、当前容量写为零，却标成 preserved，程序仍接受。
2. 引用只讨论建筑颜色的合成证据，却据此宣称测量了响应容量，程序仍接受。
3. 只比较无关标签，遗漏覆盖与响应，却给出确定结论，程序仍接受。

不通过增加关键词黑名单掩盖这些问题。字段一致性与语义判断不同；前者可程序检查，后者需要原文审读、反向条件测试和独立评价。即使让作者自填“已审查”，也不会自动解决。

## 2. 先展开问题，再逐因素寻找对照

本轮具体研究问题：疾病传播与控制为什么不能只按交通发展或科技进步单向判断？将本轮检索与阅读整理为以下关联提纲。它在阅读部分结果后写成，不是预登记的研究设计：

| 因素与关联 | 待检验问题 | 对照与目标状态 |
|---|---|---|
| 传染时间与发现 | 症状出现时已发生多少传播？ | 早期传染病可控性研究；目标疾病参数需独立查证 |
| 跨区网络与本地传播 | 减少输入与抑制本地传播是否是同一结果？ | 旅行限制研究；须判断本地传播是否已经形成 |
| 检测到实际响应 | 技术可用是否真的缩短行动延迟？ | 同一次追踪系统延迟事件中受影响程度不同的群体 |
| 覆盖、容量与行为 | 谁被找到、谁配合、谁遗漏？ | 追踪完成情况与实际被观察人群，不能只看技术存在 |
| 观测制度 | 报告增加是传播增加还是补报？ | 标本日期、报告日期与追踪日期分开 |
| 健康与社会结果 | 传播效应能否直接推出住院、死亡和经济损失？ | 分别定义结局，跨层级迁移需新证据 |

这不是因素越多越好的清单。当前材料不足以估计所有交互作用，也不足以评价当下2026年的具体防疫措施。目标是检查新方法关注的条件是否有研究意义。

### 生物特征：有理论依据，不能当作新版预测成功

[Fraser等，2004](https://pubmed.ncbi.nlm.nih.gov/15071187/)的原始研究摘要指出，可控性除基本传染性外，还取决于明显症状之前或无症状感染造成的传播比例。它支持研究“传播与发现的相对时间”；本次阅读摘要而非全文复现，没有将模型参数直接应用于新冠，也没有据此计算当前风险。

### 交通：作用需要按空间尺度和传播阶段区分

[Chinazzi等，2020](https://pubmed.ncbi.nlm.nih.gov/32144116/)采用传播模型分析旅行限制。其摘要报告的国内进程延迟与国际输入减少并非同一个指标，且单独旅行限制与同时减少社区传播产生不同模型结果。它支持拆分传播环节；这些是模型情景结果，不能伪装成政策随机试验或确定效应。

### 响应延迟：真实事件支持研究它，但效应大小仍有分歧

[Fetzer与Graeber，2021](https://www.pnas.org/doi/10.1073/pnas.2100814118)利用英格兰一次数据处理事故造成的追踪延迟，基于地区差异估计随后感染及死亡影响。作者报告较大效应，同时限定于当时英格兰制度环境。本次审读摘要与设计相关正文，未复现补充材料和估计程序；页面标记曾更新，未建立历史版本快照。

[Findlater等，2023](https://pmc.ncbi.nlm.nih.gov/articles/PMC10583033/)研究同一事件的个体及接触者记录：追踪启动平均为6天而对照为3天；次级非家庭接触者攻击率分别7.9%与5.9%。但住院与死亡差异未达统计显著，死亡估计区间很宽；追踪不完整也可能漏掉传播。

因此，延迟与传播值得纳入分析，但不能选取一篇研究的系数推出普遍死亡影响，也不能把未显著理解成证明无效。两篇研究的分析单位、覆盖、结局和追踪范围不同，不能直接投票、平均或宣称后文完全推翻前文。差异本身要求进一步核对，而不是消除。

以上是外部机制证据，不是项目的事前预测。研究者知道结局，题目也是有目的选取的，无法据此给新版准确率加分。

## 3. 对此次反思要求的落实

研究入口和检索计划增加了先展开问题的步骤：明确结果 → 找关联因素和反向路径 → 判断哪些未知会反转结论 → 分别选取历史对照 → 用当前状态和发展速度修正 → 综合交互作用并检查遗漏。

这一步的有效性要通过行为来检验：当关键条件改变时，回答是否随之改变；证据缺失时是否降低结论强度；无关因素变化时是否保持判断。不能用填了多少字段或写了多少字代替效果。

完整的下一轮行为实验应在作答前固定题集与评分：相同资料、相同模型和预算，比较普通分析、旧版方法、新版方法；使用成对变化的证据包检查条件敏感性，设置无关信息变化对照，再由不知道方法标签的评价者核对原文支持、遗漏、错误确定性与可结算结论。当前合成校验题不能充当那轮独立留出集。

真实预测另以当前真实时间登记问题、概率、期限及结算规则，等待后续结果。历史记忆污染无法通过“假装不知道后来结果”消除。
