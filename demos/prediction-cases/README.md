# 从历史到判断：三个案例

这组案例是阅读摘要，完整证据见各题报告；后续追加的纪实、采访与从业者资料见[多渠道补证](../three-question-rerun/multisource-supplement.md)。

这组案例展示如何选择历史对照、发现时代差异，并用后续结果检查判断。研究完成于 2026-10-09，作者已经知道后续事件，属于历史重建；没有把重建结果当作真实事前预测。

## 01 · 房地产：先区分行业扩张与资产价格

**问题。** 站在 1998-07-31，住房制度变化会怎样影响中国房地产？

**输入与历史对照。** 从住房制度、支付能力、融资、供给和城市化出发，检查 1994 年制度路径，并以日本 1997 年的不同条件作为反向参照。制度松绑提供可能性，需求能否转成交易还受收入、信贷和供给约束。

**形成判断。** 分别研究开发投资、成交与价格，不从“住房市场扩大”直接跳到“每年房价必涨”。在 2021-02-28 再做一次截点分析，检查融资收紧是否先影响开工等流量，再传导至存量。

**效果。** 1998—2003 年名义房地产投资增长 180.94%，商品住宅平均销售价格增长 18.50%；其中 1999 年均价仅增长 0.16%。2021 年新开工下降 11.4%，投资仍增长 4.4%。这些结果说明指标可能分化，不能据此声称预测了每座城市、每年的价格或证明单一政策的因果贡献。

**修订信号。** 居民支付能力、融资可得性、开工与销售背离、库存和区域人口变化。

## 02 · 疫情：传播与响应是两条相互竞争的链

**问题。** 站在 2020-01-30，是否可以照搬 SARS 的短期控制与恢复路径？

**输入与历史对照。** SARS 2003 提供控制成功路径，H1N1 2009 提供广泛扩散路径。类比选择要看传染发生在发现前还是发现后、网络如何连接人群，以及响应是否足够及时、覆盖是否充分、容量是否饱和。

**形成判断。** 快速测序不等于普遍及时检测；交通发达也不等于必然失控。若传播大量发生在被识别之前，或追踪容量被挤压，症状触发的控制路径会减弱。保留有效控制与持续传播两种情景，对依赖跨境和线下接触的活动研究履约及恢复风险，不给无依据的结束日期。

**效果。** 后续研究支持症状前传播是需要重视的因素；国际旅游到达数按所引用发布口径，2020 年下降 74%，2021 年仍比 2019 年低 72%。这否定简单的快速恢复外推，但并不表示本研究事前预测了两年冲击。2020 年数据后来修订为下降 73%，复核时需保留版本。

**修订信号。** 传播链可追溯程度、检测到响应的延迟、覆盖与负荷，以及同口径活动指标。后来的传播参数不能倒填成 1 月已经掌握的信息。

## 03 · AI：技术突破需要穿过组织与市场

**问题。** 站在 2022-11-30，生成式 AI 的能力提升能否直接外推为各行业同步提效？

**输入与历史对照。** 计算机与软件的生产率研究提示互补投入和组织改造的重要性；工业机器人研究提示任务替代、需求增长与收益分配可能并存。历史提供问题结构，不直接提供 AI 的就业系数。

**形成判断。** 沿“能力与成本 → 任务可用性 → 组织采用 → 完整交付成本 → 需求与收益分配”逐段检查。优先检验上下文明确、质量可核验的任务；把生成节省与核验、返工、集成成本一起计量，不直接预测全国失业率或科学突破日期。

**效果。** 2023 年特定写作实验报告耗时减少 40%；早期 2025 年熟悉成熟开源仓库的开发者实验报告耗时增加 19%。它们与收益具有任务条件的判断相容，但不同实验之间不能直接作因果比较。2026 年后续更新提示可能出现更大的提速，同时存在选择和测量问题，旧实验不能永久代表当前技术状态。

**修订信号。** 同质量完整任务耗时、返工、权限和上下文接入、采用率，以及客户是否实际付费。单位任务提效、公司利润、就业与宏观生产率必须分别验证。

## 如何复现这种研究

在已安装 Skill 的宿主中，可以提出：

```text
使用 civilization-atlas，研究某事件对指定结果的影响。
先定义对象、指标、地区、信息截点和预测期限。
核实当前证据，寻找支持与反对的历史对照，比较机制及时代条件。
列出条件判断、竞争解释、关键未知和修订信号。
若做历史回放，将截点后结果单独核对；不要计为真实事前预测。
若预测未来，先登记概率、同题基线与结算规则，再等待结果。
```

数值效果可用[全量基线回放](../historical-replay/README.md)复现；真实外部预测核对与未来登记见[电动车验证](../ev-validation/README.md)。流程可复现与预测有效是两个问题：后者需要预先登记、结果结算和同题基线比较。
