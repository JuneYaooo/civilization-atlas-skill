# 历史回放：五年外推的能力与失败

这是对数值基线的确定性回放，不是 WorkBuddy／LLM 生成判断的准确率测试，也不是历史机制增强的效果证明。

覆盖 217 个国家／经济体、5 个变量和 2000、2005、2010、2015、2020 五个截点。预测目标为五年后。线性方法仅使用截至预测截点的连续五年值，与保持截点值不变的基线比较。比例变量限制到 0—100。

预定义网格 5,425 题；可结算 4,766 题；因训练值或结果缺失排除 659 题。全部明细与排除原因保存在 [results.json](results.json)。

| 指标 | 可结算题数 | 线性 MAE | 保持不变 MAE | 线性胜／平／负 |

| wb:IT.NET.USER.ZS（percent） | 738 | 8.564 | 14.360 | 637 / 1 / 100 |

MAE 越低越好；百分比指标的误差单位为百分点。不同变量量纲不能直接合并，人口总量误差会受人口大国影响。国家、变量、预测截点存在依赖，未据此计算显著性。

## 固定展示题目

| 对象与截点 | 五年线性预测 | 后来记录的结果 | 判断 |
|---|---:|---:|---|
| 中国城市人口占比，2010→2015 | 55.52% | 57.33% | 方向相符，仍有 1.81 个百分点误差 |
| 日本人口，2010→2015 | 128,341,600 | 127,141,000 | 方向判断错误，且误差高于保持不变 |
| 巴西实际人均 GDP，2015→2020 | 9,110.43 | 8,435.01 | 方向判断错误，且误差高于保持不变 |

三题在运行前固定选定，无论成功或失败均展示；它们本身不是随机样本，完整网格结果才是数值基线的描述。

这些结果说明平滑外推可在部分持续变化指标上优于保持不变，却可能错过转折。不能由此宣布“精准预测”。历史机制研究的价值需要另做同题、同信息和相当预算的增量实验。

## 复现与信息时间

在仓库根目录运行 `python3 demos/historical-replay/replay.py --output /tmp/atlas-replay-results.json`，输出文件必须尚不存在。程序先从截点前训练值生成预测，再另行匹配结果。

输入来自 2026-09-25 取得的 WDI 快照，包含后来修订值，并非当年实际发布版本。其精确摘要保存在结果的 `database_bundle`。拟合时未使用未来行，但这仍只是历史重建；若用语言模型解释这些题目，模型也可能早已知道后来发生的事。

原始变量定义、提供机构、来源定位见知识库的元数据。运行代码和本次结果随本目录提供。
