# 房地产、疫情与 AI：历史机制审计

本次审计说明：方法能够把宏大叙事拆成有条件、有期限、可反驳的判断，但尚不能证明准确预测能力。产业规模、价格、传播范围、持续时间和生产率是不同结果；猜对其中一个不能替代其余结果。

这是 **2026-10-09 在已知结局下完成的历史重建**。四个信息截点只是约束解释所引用的资料，不会消除模型记忆、选择题目与选择期限的事后偏差。本文没有历史上提前发布的预测；“过强推断”是此次人为设置的压力测试，不是旧版 Skill 真正做过的预测。不给出命中率、校准概率或投资回报。

后续研究补充了历史对照、时代条件和多渠道材料，见[三题研究](../three-question-rerun/README.md)。本页保留初轮命题与结果，不代表后续研究的完整取证范围。

## 一、中国房地产：机会出现在制度与支付能力接通的地方

### 1998：需求怎样变成市场

“改革开放后房价上涨”跨度太大，不构成可执行预测。这里选择1998年住房制度改革作为具体观察点。[国发〔1998〕23号](https://www.beijing.gov.cn/zhengce/zhengcefagui/qtwj/201309/t20130924_776668.html)规定停止实物分房、逐步货币化，并涉及工资、公积金、个人住房贷款等购房资金渠道；政策仍强调多层次供给，不能简单理解为全部住房立即市场化。

可以提出的机制假设是：**住房需求通过制度变化成为交易需求，而融资决定其中多少需求能成为有效购买力。** 企业看到可支付订单才扩产，形成建设、材料、装修和交易服务的传导链。机会的验证点应是本地改革落实、贷款实际可得、成交与回款，而不是一则改革消息。

这解释了为什么开发投资可以迅速扩张，而平均价格并不同时暴涨：新增供给、价格构成与成交分布都可能缓冲或遮蔽价格变化。R1和R2相符，但不能由两点比较识别改革的独立因果效应；收入变化、城市迁移、土地供给等竞争解释没有被控制。以1998年度数值作结果基点，也不等于七月已知道全年数据。

**历史增量目前有限**：这一阶段的解释主要来自当时政策，尚未建立其他国家住房改革的可比样本，不能宣传为“五千年历史模型提前发现房价牛市”。下一步应比较制度改革落实不同、金融条件不同的城市，而不只研究全国上涨这一条路径。

### 2021：扩张机制也可能成为脆弱性来源

[2020年底贷款集中度政策答记者问](https://www.pbc.gov.cn/huobizhengceersi/214481/3868581/3868584/baf21ec2a2b24573a3d29c73e6a13c1b/index.html)提供了融资约束变化的线索，同时明确分类管理、过渡期及多数银行已符合要求。它不是所有贷款立刻停止的证据，也不能与其他监管政策混称。

[BIS 2012研究摘要](https://www.bis.org/publ/work380.htm)将信贷和房地产价格的中期共同波动作为金融周期的重要特征。这给出一个可迁移的问题：当销售回款和融资依赖较强时，新增项目是否比存量施工更早调整？但不能据此算出中国市场见顶的月份。

2021新开工下降而全年投资仍上升，与“新增承诺先变、存量项目后变”的时滞机制相容。这个对照比笼统预测“房地产要跌”更有信息：工程订单、材料需求、开发企业现金流、房屋价格不是同一个时间序列。它仍然只是机制相容性；要确认时滞，需要月度、地区及企业层面数据，不能用两项全国年指标完成因果识别。

主导约束因此应允许切换：早期可能是商品化与支付渠道，成熟阶段可能是现金流、负债和新增需求。不能用一次扩张经验形成永久看多规则，也不能把2024结果倒推成2021能够精确预报的结局。

## 二、新冠：历史提供竞争路径，不能提供统一倒计时

在[2020-01-30 WHO声明](https://www.who.int/news-room/detail/30-01-2020-statement-on-the-second-meeting-of-the-international-health-regulations-(2005)-emergency-committee-regarding-the-outbreak-of-novel-coronavirus-(2019-ncov))中，国际传播风险已有依据；同时存在重要未知，遏制仍被认为可能，WHO当时也未建议旅行与贸易限制。由此可以支持提高跨境活动受冲击情景的重视程度，不能把多年全球中断写成当时已确定的事实。

历史至少提供两条竞争路径：[2003年SARS得到控制](https://www.who.int/news-room/detail/05-07-2003-sars-outbreak-contained-worldwide)，以及[2009年H1N1的跨国大流行](https://archive.cdc.gov/www_cdc_gov/h1n1flu/updates/061909.htm)。二者提醒研究者检查传播特征、发现能力和干预条件，而不是挑一个故事复制持续时间。

UN Tourism在[2021年1月报告](https://www.untourism.int/news/2020-worst-year-in-tourism-history-with-1-billion-fewer-international-arrivals)中给出2020国际到达数下降74%；[2022年1月报告](https://www.untourism.int/news/tourism-grows-4-in-2021-but-remains-far-below-pre-pandemic-levels)显示2021仍比2019低72%。后者将2020降幅修订为73%；脚本保留各自发布口径，不把不同版本混成一条无修订序列。

值得关注的机制是：**冲击经由活动网络、主动避险、政策限制和组织适应传导，损失不必与当日确诊数同比例。** 这是假设框架，单靠旅游下降不能区分上述机制的各自贡献。

对应的机会研究应检查远程协作、替代交付、供应连续性是否出现实际付费需求，并区分临时需求与持久行为变化。不能从“线上娱乐或远程活动增加”直接推出任何企业盈利、估值或股价上涨。若判断的是恢复日期，需要持续更新传播和政策证据；本次应对精确日期弃权。

## 三、AI：能力进步与社会收益之间存在组织转换过程

[2022年ChatGPT发布说明](https://openai.com/index/chatgpt/)同时展示可用能力和生成似真错误内容的限制。截点之前的[生产率J曲线研究](https://www.nber.org/papers/w25148)提出通用技术需要流程、组织和无形资本配套；本次阅读的是摘要，不是整部技术史或论文全文。

可提出的条件判断是：输入清楚、结果容易检查、错误代价可控的部分任务可能更早获益；需要大量隐含背景、系统集成和责任承担的工作未必同步。这不是必然规律，也不是从技术指标外推全行业指数增长。

[MIT对2023写作实验的介绍](https://news.mit.edu/2023/study-finds-chatgpt-boosts-worker-productivity-writing-0714)报告，453名专业人员参与的特定任务中耗时下降40%、质量提高18%；任务环境不要求严格事实准确性或公司背景。与之相比，[METR早期2025实验](https://metr.org/blog/2025-07-10-early-2025-ai-experienced-os-dev-study/)在16位熟悉仓库的开发者、246项真实任务上观察到耗时增加19%。两项研究的人员、工具和任务不同，不能将差值当成同一实验的处理效应，更不能推论2026工具的当前效果。

历史视角的潜在价值，是促使我们研究**配套投入与瓶颈迁移**：内容生成变便宜后，可靠上下文、结果核验、流程接入和责任边界可能变得更重要。这是机会假设；还需要付费意愿、全流程成本和复购数据才能支持商业判断。

技术迭代快不自动意味着总生产率同速增长，更不自动证明就业净减少或基础科学突破以相同指数增长。本次未检验这三项。验证时应测量含审核、返工、集成在内的完成成本，而不是只测生成速度。

## 周易思维如何接受检验

在这些场景中，可用“时、位、变”的提问方式检查：主体的处境如何改变动机，权责如何影响合作，原来的行为为何可能在新约束下失效。它是组织人性与社会问题的解释视角，不提供数字预测参数，也不把卦象当作因果证据。

房地产中的追涨预期、疫情中的信任与避险、AI中的效率信念，都应转成可观察假设。例如，METR中参与者的主观提速感受与实际耗时不一致，说明采用意愿和生产率需要分开测量；这并未证明周易模块具有独立预测增益。若要证明增益，应在同题同预算下比较含该视角与不含该视角的分析结果，预先规定评分规则。

## 这次实际测试了什么

- 宿主读取 Skill 方法、本地查询、在线核对来源并组织假设；Python仅复算数字和核对引用日期，没有自动推断历史机制。
- 本地检索“房地产”和“artificial”没有直接命中，“COVID”只找到一条继承的声明记录。这是本轮关键词检索结果，不是数据库完整覆盖审计；外部证据不可省略。
- 所有历史输入均标注未验证当时的完整网页快照。日期检查只是必要条件；它不能检查模型记忆泄漏、网页所有修改或语义穿越。
- Copilot当前网页虽标原始日期2022-09-07，但明示2024-05-21更新，已从2022输入中剔除。
- 六项本地程序测试检查未来资料混入、已知后续修订、未知历史版本、缺测处理、增长计算和禁止冒充事前预测。程序通过不等于研究结论正确。

## 如何进一步验证预测价值

目前没有证据证明该 Skill 优于“只看当前事实”或简单趋势外推。需要另建预先固定的任务集合，覆盖有机会但未成功、繁荣与衰退、不同地区与技术，不再按已知结果挑题。

在同一信息权限与预算下，分别冻结普通分析、历史机制分析、可选周易视角的输出；同时设置简单基线。历史档案题应称为受限回放，真正的事前能力最终仍须通过从现在开始登记、等待未来结算来验证。记录概率时使用既有预测登记工具，记录真实签发时间，不倒填历史日期。

方向、幅度、时点和行动收益分开评分；保留缺答、失败、置信度及政策干预后的修订记录。条件没发生、指标换口径或事后缩小适用范围，都不能自动算命中。

## 方法审计后的修正

本次方向核对没有逐条测量历史与目标环境的传播、发现、响应、部署覆盖及阶段变化，因此不能据此证明机制迁移有效。后续研究按[机制与时代条件协议](../../references/mechanism-transfer.md)追加新记录；本次原始输入与结果保持不变，不补写成事前判断。
