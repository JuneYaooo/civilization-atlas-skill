# 第二轮核验：指标、制度与反例

核验日期：2026-10-09。材料包括政策原始说明、议会答复和另一期注册统计；未补齐消费者经历、有效成交价格和各国因果识别。这里检验的是论断边界和计算规则，不是证明预测模型有效。

## 1. 份额低于政策标题，不等于不合规

英国2024年BEV份额19.6%，不能直接与ZEV目标22%相减后宣称违规。按[2023年政府政策说明](https://www.gov.uk/government/consultations/a-zero-emission-vehicle-zev-mandate-and-co2-emissions-regulation-for-new-cars-and-vans-in-the-uk/outcome/zero-emission-vehicle-zev-mandate-consultation-summary-of-responses-and-joint-government-response)，制度包含交易、借用和CO₂额度转换；2024年实施地域是英格兰、威尔士、苏格兰，而非完整英国。ZEV定义也不等同于统计表中的BEV。

[交通部2025-01-16议会答复](https://questions-statements.parliament.uk/written-questions/detail/2025-01-07/hl3848)表示，考虑CO₂转换灵活性，政府认为汽车市场整体符合22%目标。这是当时政府的判断，不是本项目逐家核验后的合规结论。

因此应分开三个命题：实际采用份额、政策目标、按制度计算的合规结果。SMMT的22.3%市场预测与22%政策目标也不同；原有2.7个百分点预测误差计算保留。若把目标直接当作销量下限，会误估企业必须增加销量的压力。

## 2. 用另一季度试跑，并主动补充相反结果

从[ACEA 2026年3月报告](https://www.acea.auto/files/Press_release_car_registrations_March_2026.pdf)第4页抄录同表2025与2026年第一季度BEV和总注册量。四个原市场之外，看到结果后加入荷兰和比利时作为开发反例，不改原来四题的未来登记。

| 市场 | 2025Q1份额 | 2026Q1份额 | BEV注册量差 |
|---|---:|---:|---:|
| 德国 | 17.00% | 22.82% | +46,662 |
| 法国 | 18.17% | 27.91% | +37,564 |
| 英国 | 20.70% | 22.38% | +17,423 |
| 挪威 | 89.01% | 97.95% | −2,006 |
| 荷兰 | 35.47% | 30.52% | −7,544 |
| 比利时 | 33.41% | 34.68% | −933 |

这里的反例约束推理：共同技术趋势不足以推出每个市场都增长；份额上升不足以推出新增销售规模扩张。挪威和比利时直接呈现后一种分离。原始输入及复算见[quarterly-input.json](quarterly-input.json)、[quarterly-results.json](quarterly-results.json)。

这不识别各国变化的原因；未根据结果补写“早就能预测”。荷兰、比利时是事后选择，不能用于计算总体误报率。季度采用变化也不是社会历史转折的充分证据。

## 3. 计算层的实际检验

[quarterly_check.py](quarterly_check.py)用整数交叉乘积比较份额，拒绝缺失值、布尔值、浮点计数、负数、零分母、分子大于分母，以及错误时间、总体口径和重复市场。它只处理本次已知结果的试跑，不能结算2027年题目。

[test_quarterly_check.py](test_quarterly_check.py)覆盖7项测试，包括：真实计数相等归否；舍入后相等但实际增长；销量下降而份额增长；无效计数拒绝；未加权月度平均可反转方向；元数据混用拒绝；归档输出可复算。人工录入的口径标签仍须对照原文，脚本不能检测被错误标注为正确口径的数字。

```sh
python3 demos/ev-validation/quarterly_check.py
python3 -m unittest discover -s demos/ev-validation -p 'test_*.py' -v
```

## 4. 这次核验改变了什么

今后解释政策或历史突破时，应先列出观测指标和真实目标之间的映射：对象是否相同、地域是否相同、时间窗口是否相同、是否存在替代履约方式、分母如何变化。任何一处不同，都不能直接当作同一个结果。

机会研究还需沿着“技术可行 → 实际采用 → 付费规模 → 可保留利润”逐层取证。此次仅核对注册量和采用份额，尚未核验价格、收入、利润或因果路径；因此没有得出投资机会成立的结论。

原四国任务冻结文件未变，未来结算数仍为0；没有生成未经校准的概率，也没有把本轮复算当作事前预测。趋势基线与完整方法的同题比较仍待提交。这一轮增加了反例和错误拦截证据，不能宣称已证明历史方法优于简单基线。
