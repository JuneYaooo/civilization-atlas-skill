# 首批验证题：电动车采用与条件变化

建立日期：2026-10-09。选择德国、法国、英国、挪威，研究同一技术背景下的不同采用状态。四国是目的性选择，具有共同政策、供应链和宏观冲击，不是四个独立实验，也不代表全球。

当前完成：核对四国2023—2024注册数据、复算数量和份额、核对一份真实发布的外部预测，并冻结四个未来问题。尚未完成：Skill的四国事前预测、同预算方法比较及未来结果结算。本验证题集测量采用变化，不能把季度增长当作历史转折成立。

后续核验见[第二轮报告](audit-2026-10-09.md)：核对英国制度口径、复算2025—2026年第一季度六国数据，并加入荷兰和比利时反例及7项计算测试。

## 已核对的历史检验材料

| 对象 | 2023→2024纯电新车份额 | 2024纯电注册量变化 | 应当检验的方法弱点 |
|---|---:|---:|---|
| 德国 | 18.43%→13.51% | -27.40% | 技术进步是否被误推为各地持续增长；支付条件和企业响应如何影响路径 |
| 法国 | 16.80%→16.91% | -2.55% | 数量下降、份额上升可以共存；结果口径不清会产生伪命中 |

| 挪威 | 82.38%→88.89% | +9.38% | 高渗透状态的进一步增长与其他市场不可直接等比外推 |

数据统一取[ACEA 2025-01-21报告](https://www.acea.auto/files/Press_release_car_registrations_December_2024.pdf)第4页BEV及TOTAL列。计算见[historical.json](historical.json)、[results.json](results.json)。纯电BEV不包含插混或普通混动，注册量不是车队保有量。没有用这四个结果给Skill打命中分。

额外核对发现，[OFV现行页面](https://ofv.no/aktuelt/nybilsalget-i-2024-9-av-10-nye-personbiler-var-elbiler)在2026年更新，挪威计数与ACEA早期PDF略有差别。此处保留统一ACEA版本，不混合版本，也不推定差异原因。

### 真正的旧预测可以怎样用

[SMMT 2023年10月版展望](https://www.smmt.co.uk/wp-content/uploads/WEBSUM-SMMT-CAR-LCV-MARKET-OUTLOOK-Q4-06-11-2023-FINAL.pdf)预测英国2024年BEV份额22.3%；[2025年1月结果报告](https://www.smmt.co.uk/record-ev-market-share-but-weak-private-demand-frustrates-ambition/)给出19.6%，按公布舍入值高估2.7个百分点。后者也提示私人买家与车队结构差异。此为第三方当年预测，本项目只是现在核对，不能宣称本项目优于它；行业协会同时有政策倡议立场，原因解释须另查。

### 德国不能只看补贴取消

[政府公告索引](https://www.foerderdatenbank.de/FDB/Content/DE/Pressemitteilung/2023/12/16-umweltbonus-endet-am-17-12-2023.html)确认2023-12-17补贴终止信息；原公告页面本轮返回429，未阅读全文。[smart 2023-12-18原始声明](https://media.smart.com/de-DE/261080-nach-ende-der-forderung-smart-ubernimmt-den-umweltbonus-fur-alle-privatkunden/)则记录限定订单、注册时间的厂商补偿安排。政府取消补贴与消费者实际支付变化之间还隔着企业响应，不能只用一项政策解释全年结果，也不能从一家品牌推广到全市场。

下一步取证应逐国补充有效成交价格与融资成本、私人/车队结构、充电可及性、替代车型及真实购车者经历。论坛中有关订单和补贴损失的帖子本轮仅作检索线索，未作为身份已核实的证言。没有将当前资料倒填为2023年输入。

## 已冻结的未来四题

德国、法国、英国、挪威各一题：**2027年第一季度，新注册乘用车中BEV份额是否严格高于2026年第一季度？**

任务集合已用 `forecast_registry.py` 在外部研究目录冻结，归档副本为[taskset-frozen.json](taskset-frozen.json)。登记问题不等于发布预测；没有概率、方向提交或未来成绩。

- 预测截止：2026-12-31 00:00 UTC，事件窗口为2027-01-01至2027-04-01（不含终点）。
- 结算起点：2027-05-15。指定ACEA截至该日的2027年3月累计报告及勘误，以同一可比表的两年整数注册量计算，不平均月度份额，不只比较已四舍五入百分比。
- 相等为否；缺表或不可比保持未结算，至2027-06-30仍不能恢复指定版本则无效。不能把缺数据记作未增长，也不能因为政策改变而删题。
- 后续修订另存，不能覆盖首结算；所有四题都保留，包括弃权、反例和不利结果。

注册文件完整记录公式和口径；本地摘要用于检查文件完整性，不是第三方认证时间戳。未来结算不能提前完成。

## 比较方案

先取得并冻结同一截止的输入，再同时提交：只用近期同口径趋势的基线、加入历史条件迁移的研究判断。纯无信息0.5可另作参考，不能冒充经验基线。概率没有校准依据时明确弃权；定性路径另存，不强行编造概率。所有方法的任务、截止、研究预算和结算来源固定，不能看完结果再改阈值。

因为历史案例及结果已被看过，本轮只能用于开发；同一研究者也不能将自己扮演两种方法称为独立盲测。四题样本过小且相关，只能作为先导研究，不能证明通用预测能力、校准或因果。判断收益需另有行动成本与执行记录。

复算历史数据：

```sh
python3 demos/ev-validation/check.py
```
